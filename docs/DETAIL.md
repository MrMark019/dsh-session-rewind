# 撤回本轮

把一次已经跑完的提问收回去：对话切到本轮之前，工作区文件还原到本轮开始前的快照。

## 怎么用

每条已完成的回复下方、复制与分支图标那一行的上方，会出现一个细小的回转箭头。点它：

1. 弹出确认框，里面先显示本次会动到多少文件（「将还原 N 个文件，删除 M 个本轮新增的文件」）。
2. 勾选「同时还原工作区文件」时，确认后会先把工作区还原到本轮开始前，再新建一个会话分支并打开它。
3. 取消勾选时，只撤回对话，工作区文件保持现状。

撤回后的新会话里，本轮提问和它的回答、以及之后的所有轮次都不存在；原会话仍完整保留在侧边栏，随时可以回去查看。

## 它做了什么

**对话**：DSH 的会话日志是只追加的事件流，没有原地截断的接口。撤回用的是 Harness 自带的 `session.fork`（和「分支」按钮同一机制），切点取在本轮 `turn/start` 事件的前一个 seq，因此整轮被切掉。

**文件**：每轮开始时把工作区写成一个 Git tree 对象，存进本会话私有的对象库：

- 只写私有目录（系统临时目录下的 `dsh-session-rewind/<会话 id>`），仓库的 `.git` 对象库只读挂载为 alternate；
- 不写仓库的索引内容、引用与工作树之外的任何东西；还原后只刷新被还原文件的索引 stat 缓存，已暂存内容不变；
- 还原走 `git read-tree` + `git checkout-index`，二进制文件、符号链接、配置过的 smudge/LFS 过滤器与正常 checkout 一致；
- 本轮新增的文件会被删除，本轮删除的文件会被找回；被忽略的未跟踪文件既不还原也不删除。

## 限制

- **需要 Git**：工作目录不在 Git 仓库里时只能撤回对话（对话框里会说明）。
- **安装前的轮次没有快照**：可以撤回对话，但不会还原文件。装好之后跑过的轮次才有快照。
- **快照可跨重启**：每轮的快照索引写在会话私有目录的 `index.json` 里，对象也在同一目录，Host 重启后仍能还原；只有超过 7 天没人动过的残留目录会在启动时清掉。
- **快照失败会自报原因**：抓取失败时对话框会显示失败原因，同时在私有目录留一份 `snapshot-error.log`。
- **忽略文件不追踪**：`node_modules`、构建产物等被 `.gitignore` 覆盖的文件既不在快照里，也不会被删除。
- **首次快照有成本**：第一次快照会把工作区里未被忽略的文件写进私有对象库；之后的快照只处理变化的部分。
- **会话仍在运行时不能撤回**：需要等这一轮结束、会话空闲。
- 工作区是本轮之后又换过仓库根目录时，文件还原会被拒绝。
- 单次还原最多处理 `maxFiles` 个路径，超过则拒绝。

## 配置

```yaml
- id: session-rewind
  name: '@mrmark019/dsh-session-rewind'
  config:
    restoreFiles: true      # 关掉后对话框里不再提供文件还原
    maxFiles: 500           # 单次还原允许的最大路径数
    timeoutMs: 30000        # 单条 git 命令的超时
    maxScanEvents: 20000    # 装载历史轮次索引时允许扫描的事件上限
```

`maxScanEvents` 控制「装插件之前的会话也能撤回对话」这项能力：事件数超过上限的会话不再补历史索引，只保留装好之后跑过的轮次。

## 自测

三个脚本都不依赖 Cordis，直接跑：

- `node scripts/selftest.mjs`：在系统临时目录建一个一次性 Git 仓库，验证快照 → 改动/删除/新增 → 还原后工作树与快照 tree 完全一致、`git status` 干净、二进制逐字节相同、被忽略文件未被触碰、暂存内容与仓库对象库均未改变。
- `node scripts/hosttest.mjs`：用桩 Context 加载 Host 入口，模拟 `turn/start`、`tools/pre-execute`、`turn/end`，验证快照记录、路由注册、运行中拒绝、`atSeq` 计算、文件还原与「只撤回对话」两种路径。
- `node scripts/clienttest.mjs`：用桩模块加载器与最小 React 垫片加载浏览器入口，验证两个槽位注册、注入面、按边界渲染按钮、打开对话框时发出 dryRun 请求。

三个脚本都在结束时自行清理。
